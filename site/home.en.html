What is LuxOS?

LuxOS is a fast, lightweight Linux distribution based on Arch Linux with a macOS-like desktop (Xfce underneath). It has its own package manager lux, its own kernel linux-luxos, automatic drivers, the AI assistant LuxAI, the terminal coding agent Lux Code and its own programming language LSL. It is a rolling release, currently in beta. The ISO is a free download below.

⚙How to install

  1. 1

    Write the ISO to a USB drive (at least 4 GB), for example with Fedora Media Writer, balenaEtcher or the dd command.

  2. 2

    Boot your computer from it (the boot menu is usually on F12, F11 or Esc) and try LuxOS without installing.

  3. 3

    The installer offers the whole disk, free space next to Windows, an existing partition and encryption.

  4. 4

    Existing installations update themselves or with lux update – they do not need the ISO.
