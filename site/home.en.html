Plug and play

Plug it in, turn it on – LuxOS sets it up. This is what works without you doing anything:

Graphics

Intel, AMD and NVIDIA – older GeForce cards included – get the right driver. On hybrid laptops games use the NVIDIA GPU by themselves in Performance mode.

Wi-Fi, sound and cameras

Broadcom Wi-Fi, laptop speakers and microphones (Intel Smart Sound) and Intel IPU6 cameras are detected and installed for you.

Printers and scanners

Modern printers and scanners work without drivers – connect them by USB or on the network and print or scan.

Touch screens

A touch screen is found at sign-in and the on-screen keyboard, gestures and touch scrolling turn on. Computers without one are not changed.

Displays

A second monitor just works; Control Center switches between Mirror and Extend, and scaling up to 200 % keeps sharp screens readable.

Updates you can undo

Updates install in the background with a snapshot before each one – lux rollback or the boot menu takes you back.

Made for touch, too

Since 1.0.5 LuxOS works fully on tablets, 2-in-1 laptops and touch monitors – even without a physical keyboard. Nothing to set up.

  • The on-screen keyboard appears when you tap a text field – in apps, Launchpad, Search, on the sign-in and lock screen.
  • Install by touch only: the live system on the ISO works the same way.
  • Firefox scrolls with a finger and zooms with two; the pointer hides while you touch.

Gestures

  • 3 fingers upLaunchpad
  • 3 fingers downShow the desktop
  • 3 or 4 fingers left / rightSwitch workspace
  • Pinch with 3 fingersClose the window
  • Tap with 2 fingersRight click
  • Swipe in LaunchpadChange sorting

What is LuxOS?

LuxOS is a fast, lightweight Linux distribution based on Arch Linux with a macOS-like desktop (Xfce underneath). It is plug and play: drivers set themselves up, touch screens work and updates can be undone. Apps come from the Arch Linux repositories and Flathub – through the LuxOS Store or the simple lux command, which replaces pacman. It uses its own kernel build linux-luxos. Optional extras are the AI assistant LuxAI, the terminal coding agent Lux Code and its own programming language LSL. It is a rolling release; 1.0.3 is the first stable version. The ISO is a free download below.

Why LuxOS

What you get compared with Windows or a typical Linux distribution.

Free, with no paid edition

The ISO is a free download. Most of LuxOS is open source (GPL-3.0-or-later); LuxAI, Lux Code and LSL IDE are free to use on LuxOS.

Fast on older computers

A light Xfce desktop with zram swap, earlyoom and its own linux-luxos kernel. A 64-bit PC and a 20 GB disk are enough; tested in virtual machines with 3 GB of RAM.

A familiar macOS-style desktop

Top bar, Dock, Launchpad, Search and Control Center – easy to learn whether you come from Windows or a Mac.

Apps from Flathub and Arch

The LuxOS Store offers Flathub and the Arch Linux repositories; checked AUR packages are built in a sandbox. The lux command replaces pacman with plain words – type a pacman command and LuxOS shows the lux one. The packages are Arch’s, so Arch Wiki guides still help.

Help when you need it

Documentation for every part of the system, release notes for each version and a Discord community where questions get answered.

Updates you can undo

LuxOS Care installs updates in the background, takes a Btrfs snapshot before every update (lux rollback) and keeps the previous kernel in the boot menu.

Secure by default

Signed LuxOS repositories, the firewall on, Secure Boot support, Lux Guard checks programs from the internet and runs risky ones only in the Sandbox, and Safe encrypts a folder.

Private, no account

The system needs no account. Firefox comes without telemetry and needless connections to Mozilla. The only statistic is an anonymous weekly count (version and channel, no ID) that you can turn off.

Simple, safe install

A graphical installer – language, keyboard, disk, account – with no terminal. It can put LuxOS into free space next to Windows and checks first that Windows can be shrunk safely (Fast Startup and hibernation off).

Backups and undelete

Backups saves your home folder every hour to a USB or network disk, and Lux Guard keeps hourly snapshots of your files, so deleted files come back.

In your language

English and 12 more languages, including Czech, Slovak, Polish, German, Ukrainian and Hungarian; a new install gets Firefox and Thunderbird in the system language too.

Optional AI assistant

LuxAI is optional and off until you sign in – without an account nothing is sent anywhere, and lux remove luxai removes it. Signed in, it explains errors, changes settings and searches the web for you; the free account includes 20 000 credits a month.

⚙How to install

  1. 1

    Write the ISO to a USB drive (at least 4 GB), for example with Fedora Media Writer, balenaEtcher or the dd command.

  2. 2

    Boot your computer from it (the boot menu is usually on F12, F11 or Esc) and try LuxOS without installing.

  3. 3

    The installer offers the whole disk, free space next to Windows, an existing partition and encryption.

  4. 4

    Existing installations update themselves or with lux update – they do not need the ISO.
