What exactly is sent

Once per calendar week (an ISO week starting on Monday, in UTC), when the package manager lux downloads the package lists – LuxOS Care does this automatically – it makes one extra request to https://luxos.lux-ai.cz/countme with only these four values:

ValueMeaningExample
vLuxOS version1.0.0
archProcessor architecturex86_64
chUpdate channelstable or staging
ageHow long the system has been installed: 1 = first week, 2 = up to a month, 3 = up to six months, 4 = longer3

The whole request then looks like this:

https://luxos.lux-ai.cz/countme?v=1.0.0&arch=x86_64&ch=stable&age=3
  • Nothing else is sent: no unique ID, no computer name, no hardware details, no list of installed apps and no user data.
  • The server keeps only weekly counters for each combination of week, version, architecture, channel and age – that is all this page shows.
  • IP addresses are not stored. Access logging is switched off for /countme. To filter out duplicates the server uses a keyed hash of the IP address; the key is random, lives only in memory and is thrown away every week, so the hashes cannot be linked to anyone or across weeks.
  • The numbers are an estimate. Computers that are switched off or offline for a whole week are not counted. Several computers behind one shared IP address (a school, an office) may be counted only once per week and version – a simple protection against spamming.

The idea is inspired by Fedora’s DNF countme.

How to turn it off

Counting is on by default and can be switched off at any time, in any of these ways:

  • In the Software Update app: the Privacy switch.
  • In the terminal: sudo lux-config set-countme off
  • In /etc/lux/lux.conf: countme = false in the [general] section.
  • In the system configuration /etc/luxos/system.lsl: "updates": {"countme": False}
  • When installing: the installer has a checkbox for it (checked by default).
