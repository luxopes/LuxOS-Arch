# Klávesové zkratky

LuxOS používá klávesu **Super** (klávesa Windows) tam, kde macOS používá Cmd. Všechny globální zkratky
lze zobrazit a změnit v aplikaci **Klávesové zkratky** (`luxos-shortcuts`); rozložení klávesnice se
nastavuje v aplikaci **Rozložení klávesnice** (viz [Klávesnice a zkratky](keyboard.html), anglicky).

## Plocha

| Zkratka | Akce |
|---|---|
| `Super+Mezerník` | Hledání (přijímá i dotazy pro LuxAI) |
| `Super+A` nebo samotná `Super` | Launchpad |
| `Super+Q` | zavřít okno |
| `Super+M` / `Super+H` | minimalizovat |
| `Super+Tab` | přepínání oken |
| `Super+↑` / `Super+←` / `Super+→` | maximalizovat / půl obrazovky |
| `Ctrl+Super+F` | celá obrazovka |
| `Super+Shift+3` / `4` / `5` | snímek obrazovky / výřezu / nástroj pro snímky |
| `Super+L` nebo `Ctrl+Super+Q` | zamknout |
| `Super+Alt+Esc` | správce úloh (vynutit ukončení) |
| `Super+,` | Nastavení |
| `Super+P` | monitory: rozšířit, zrcadlit, jen externí, jen vestavěná |
| klávesa Kalkulačka | Kalkulačka LuxOS |

## LuxAI

| Zkratka | Akce |
|---|---|
| `Enter` | odeslat (nebo `Ctrl+Enter`, podle Nastavení) |
| `Esc` | zastavit odpověď nebo běžící příkaz |
| `Ctrl+N` | nová konverzace |
| `Ctrl+F` | hledání v konverzacích |
| `Ctrl+,` | nastavení |
| `Ctrl+V` | vložit obrázek nebo soubory |
| `Ctrl+Q` | konec |

## Lux Code

| Zkratka | Akce |
|---|---|
| `Enter` / `Alt+Enter` | odeslat / nový řádek |
| `Ctrl+C` nebo `Esc` | přerušit; `Ctrl+C` na prázdném řádku skončí |
| `Ctrl+V` | přiložit obrázek |
| `F2` / `F3` | změny a plán / podrobnosti nástrojů |
| `/` | nabídka příkazů |

## Rozložení klávesnice

Ve výchozím nastavení se rozložení přepíná stiskem obou Shiftů současně. Další možnosti (Alt+Shift,
Ctrl+Shift, Caps Lock, klávesa Menu nebo jen vlajka v horní liště) jsou v aplikaci Rozložení klávesnice.
