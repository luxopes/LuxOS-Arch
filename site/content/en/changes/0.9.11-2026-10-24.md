## 0.9.11 "Polaris" – 2026-10-24 (beta)

### New
- **LuxAI searches the web** (`web_search`, `web_fetch`) in all modes: search via the LuxAI server, otherwise DuckDuckGo; only public addresses are fetched (no home network or localhost, even after a redirect), at most 2 MB. Web content is marked as untrusted data; once it is in the conversation, every command in Agent mode needs confirmation (even in administrator mode), and addresses that neither the user wrote nor the search returned open only after confirmation.
- LuxAI: LaTeX formulas are rendered (fractions, sums, integrals, subscripts, Greek letters), code gets syntax highlighting (Python, LSL, Bash, JS, C/C++ and more), text can be copied (Ctrl+C, a Copy button on answers and code blocks).
- **Manual pages** from the LuxOS documentation: `man luxos`, `man lux.conf`, `man lsl`, `man 7 lsl`, `man lslc`, `man luxos-sandbox`, `luxos-safe`, `luxos-guard`, `luxos-care`, `luxdrop`.
- **Notification history** – the bell in the top bar keeps the last 100 notifications (time change, Calendar, LuxOS Care…); volume and brightness are not stored.
- Installer: bigger **Everyday use** set (VLC and codecs, KeePassXC, PDF Arranger, Disks, Transmission, Office-compatible fonts) and **Programming** set (openssh, curl, wget, rsync, clang, cmake, gdb, Go, Rust, Podman, neovim, tmux, ripgrep, fzf, …).

### Fixes
- **Brightness by scrolling on the battery icon** – the icon and percentage buttons in `xfce4-genmon-plugin` did not pass scroll events on (the 0.9.8 fix worked only on the empty margin). You need to log out once after the update.
- **Launchpad** highlights the app under the mouse without the grid scrolling by itself (patched `rofi`, option `-hover-no-scroll`); Launchpad no longer lists itself.
- **The lock and login screens** show the user's desktop wallpaper (following light/dark mode) instead of cycling other wallpapers; new default screensaver "Desktop wallpaper and clock".
- **Screenshots** are saved to Pictures › Screenshots, not to the desktop.
- LuxAI Account: a strong password is green (not red), and the needless "Create account" link is gone from the New account tab.
