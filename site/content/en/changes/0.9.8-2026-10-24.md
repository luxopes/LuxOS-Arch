## 0.9.8 "Polaris" – 2026-10-24 (beta)

### New
- **Brightness with the mouse wheel** over the battery in the top bar (`luxos-brightness up|down`, 5 % steps, at least 10 %, the same indicator as the brightness keys). Own `xfce4-genmon-plugin` package (4.3.0-1.1) with a `<scroll>command</scroll>` tag.
- **Daylight saving time reminder** (`luxos_timechange` in `luxos-hub`): only in time zones with a time change, the evening before (18:00) and the morning after, with a switch in Desktop and Dock › Top Bar and a Turn off button in the notification.
- **Lux Store: formatted update progress** – step, progress bar, package list (old → new version, status), summary and restart recommendation; the technical log is under "Details".

### Fixes
- **LuxOS kernel on older installations**: installations without `luxos-care` (older installer) never switched to `linux-luxos`. `luxos-desktop` now requires `luxos-care`, and installing it triggers the switch (outside the installer chroot).
- An open top bar menu (e.g. Sound) blocked keyboard shortcuts and the right mouse button: Super, Ctrl+Alt, Alt+Tab, Alt+F4 and PrtSc shortcuts close the menu and run; the right button switches between menus like the left one; tapping Super opens Launchpad even with a menu open.
- Top bar context menus no longer start with the grey, unclickable name of the plugin (e.g. "Keyboard Layout") – GTK module `luxos-panel-menus`.
- Log out, restart and shut down: instead of windows with black bars (the compositor ending), the screen fades smoothly to black (`luxos-session-cover`).
- Battery saver no longer switches the screen to 60 Hz (the refresh rate change blanked it for a moment); optional "Lower the screen to 60 Hz" in Battery and Power.
- Launchpad scrolls by rows with the wheel instead of jumping a whole page.
- fastfetch in every new terminal window (not in a nested shell).
- CPU timer (TSC) falsely marked as unstable (e.g. Ryzen 5000 in laptops, the system then read time from the slow HPET): LuxOS Care adds `tsc=nowatchdog` to the LuxOS boot entries once after boot, only on CPUs with an invariant TSC.
- `rtkit` (PipeWire without real-time priority) and `wireless-regdb` (Wi‑Fi without country rules) were missing – now dependencies of `luxos-desktop`.
- The I/O scheduler rule was also tried on partitions (a warning in the boot log).
