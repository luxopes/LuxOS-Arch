## 0.9.2 "Polaris" – 2026-10-22 (beta)

### New
- More keyboard layouts in the installer (text and graphical) and a Keyboard Layout app: settings for all users and the login screen, choice of switching keys.
- Keyboard shortcuts: change, disable, custom shortcuts, conflict check, restore defaults.
- Newly connected headphones / speakers (Bluetooth, USB, HDMI) become the sound output right away.

### Fixes
- Older installations update without "unresolvable package conflicts" (lux and LuxOS Care depend on a generic package engine; lux-engine replaces it only with the new lux).
- The keyboard flag in the top bar opens Keyboard Layout.
