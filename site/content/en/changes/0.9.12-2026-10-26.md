## 0.9.12 "Polaris" – 2026-10-26 (beta)

New ISO: ISOs 0.9.7–0.9.11 failed on computers with DKMS drivers (NVIDIA, Broadcom) with "target not found: linux-luxos-headers" – the kernel headers are back on the ISO.

### Fixes
- **The Terminal no longer freezes** – the prompt (starship) has a time limit and a fallback prompt; ssh/sshfs detects a dead connection within ~45 s (`/etc/ssh/ssh_config.d/50-luxos-keepalive.conf`). Before, a disconnected sshfs folder in the home folder hung every new terminal (no prompt, no Ctrl+C).
- **Lux Code no longer freezes** with a network folder in the working directory: the change snapshot before a command (also `background_shell`) and the tools `list_files`, `find_files`, `search_text`, `directory_tree` do not cross into other mounts (sshfs), and the snapshot has a time limit.
- **A multi-line command** pasted into the terminal runs on Enter (an unfinished block such as `if` without `fi` still adds a line).
- **Sharp icons in Alt+Tab** – GTK3 sends only a 48 px window icon for SVG-only icons; LuxOS adds a 128/192 px icon from the theme to the window (Files, Drivers, Setup Assistant, Battery…).
- **Brightness via the scroll wheel** shows a single indicator, not a new one under each step.
- **Battery saver no longer turns off GTK animations** – that stopped progress spinners (the Store looked stuck while checking for updates).
- **Notifications**: no message for every network connect/disconnect; "No internet" only after 60 s and only as a transient notification; Power Manager error "Action suspend already in progress" after closing the lid (Vault did not release its sleep inhibitor).
- **lux**: an installation error also prints the first lines of the real cause; a 404 from a mirror is reported as an outdated package list ("run lux update first") instead of advice to check the internet. Interactive `lux`: long descriptions no longer scroll sideways, the preview has no technical fields.
- **Installer**: closing the window asks first (not possible during installation); 5 download attempts; a package missing from the medium is reported directly instead of "check your internet"; the default keyboard is US (the local layout is added as the second one); LuxAI sign-in right after connecting to Wi‑Fi is retried when the connection is not up yet, and a wrong clock has its own message.
