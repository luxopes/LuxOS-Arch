## 0.9.10 "Polaris" – 2026-10-24 (beta)

### New
- **Verified printer and scanner drivers** – a new signed repository `[luxos-drivers]`: vendor drivers from the AUR (Brother, Canon, Epson, Kyocera, Ricoh, Samsung, Xerox) are reviewed by `drivers/luxdrv.py` (allowed vendor sources, install scripts, changes against the last approved version on every update) and built offline from verified files. 689 drivers, an index of 4,354 printer models and 233 scanner USB IDs. When you connect a printer, its driver installs by itself (e.g. Samsung Xpress M2026 → `samsung-unified-driver-printer`), without a password. Existing installations get the repository with the `lux-engine` update.
- **Community packages (AUR), safely** – `lux install` searches in this order: LuxOS/Arch repositories → `.lux` apps → Flathub → community (AUR). The package script is checked by fixed rules (all package files, including an install script of any name; symlinks are forbidden) and by LuxAI Lite; it is built and installed in the Sandbox, into the system only with `--system` or by typing the word "system" in the terminal, and never if the script is dangerous. LuxAI does not install community packages.
- **Flathub in lux and Lux Store** – e.g. `lux install zoom`; the size includes the shared runtime, `lux remove` also removes Flatpak apps (with confirmation) and unused runtimes, and `lux update` cleans them up too.

### Fixes
- **A wrong password no longer locks the account** – instead of the default 3 failures / 10 minutes, `pam_faillock` locks only at brute-force rate (20 failures in 30 s) for 1 minute, so a failed fingerprint or a closed lock dialog cannot lock the account. When locked, the login screen says "Too many failed attempts…" instead of "Wrong password".
- `lux check`: the database lock was released too early.
