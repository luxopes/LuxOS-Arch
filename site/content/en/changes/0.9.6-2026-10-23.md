## 0.9.6 "Polaris" – 2026-10-23 (beta)

### New
- LuxAI 1.0.0-10: administrator mode – Settings › Agent permissions › Administrator commands (password every time / no password with confirmation / no password and no asking; no password only with the Flash model). Hard blocks (deleting the system, formatting disks, bootloader, accounts, sudo/polkit/PAM, package signatures) always apply; log in `~/.local/state/luxai/root-commands.log` and `journalctl -t luxai-root`.

### Speed
- Frequently run top bar programs are in LSL instead of bash (`packages/luxos-desktop/files/lsl`, compiled by `lslc` 0.10.5 at build time): battery every 20 s 9.6 ms → 1.6 ms without an awk process, app name on every window switch 7.4 ms → 1.5 ms, clock every 3 s 1.7 ms → 1.4 ms, click on Control Center and clock 4.5–5.3 ms → 1.0 ms, internet check directly from NetworkManager over D-Bus (11.6 ms → 4.6 ms). Same output and translations (TSV `luxos-i18n`); invalid `<`/`>` markup in the app name fixed. Measurements and plan for further rewrites: `docs/perf/lsl-rewrite-plan.md`.

### No pacman
- LuxOS no longer even has a pacman configuration: the package manager is configured in `/etc/lux/lux.conf` in its own format (`key value`, `repo NAME` blocks with indented `server`/`mirrors`, `hold` instead of `IgnorePkg`, `include /etc/lux/conf.d/*.conf`, `aur`, `flatpak`, `clean-keep` settings in the same file). Errors name the file and line; `lux config check`/`edit`/`show`/`engine`. The engine configuration `/run/lux/engine.conf` is generated by `lux-config` and nobody edits it.
- New locations: database `/var/lib/lux`, cache `/var/cache/lux/pkg`, log `/var/log/lux.log`, keyring `/etc/lux/keyring`, hooks `/etc/lux/hooks`, mirrors `/etc/lux/mirrorlist` (one address per line; `lux mirrors` and reflector.timer convert reflector's output).
- The engine's internal tools are called `lux-engine`, `lux-engine-key`, `lux-engine-conf`, `lux-engine-db-upgrade` (`/usr/lib/lux/alpm/bin`); no `pacman*` file in the system. The engine remains libalpm from Arch Linux.
- Without `pacman-contrib`, `pacman-mirrorlist` and `expac`: own cache cleaning (`lux clean`, LuxOS Care), update checks into a temporary database copy (`lux_alpm.py check-updates`, Store, `lux doctor`), merging of `.pacnew`/`.pacsave` (`lux configs`) and the package list for the TUI and the Store.
- Migration on update: the `00-lux-engine-migrate` hook moves the database, cache, keyring, hooks and log (by renaming, safe against power loss), converts custom repositories and options from `/etc/pacman.conf` and the sorted mirrors; the old paths stay as links until restart, then `lux` cleans them up (copy in `/var/lib/lux/migrated-from-pacman/`).

### Changes
- The session process `luxos-daemon` is now called `luxos-hub` (Calendar and Control Center in the background: `--background`); LuxOS texts no longer use the word "daemon" (LuxDrop: "Avahi"). After the update, the new name takes effect after logging out and back in.
- The `lsl` package in `[luxos-apps]` is 0.10.5 (target `linux-x86_64-gnu`, glib/gio/gtk modules, small programs with ~136 kB of memory). Top bar programs start in under 1 ms (battery 0.94 ms, clock 0.73 ms, app name 0.57 ms in a VM).
