## 0.9.1 "Polaris" – 2026-10-22 (beta)

### New
- Screenshot: a floating bar (Print, Shift+Super+5) – full screen, window, selection, recording the screen or a selection, options (where to save, timer, pointer); Shift+Super+3/4 directly.
- Displays: resolution, refresh rate, rotation (with a 15 s confirmation) and text size.
- Fingerprint login (login screen, lock screen, sudo, authorisation prompts); Fingerprint app.
- What's New: after updating to a new version, the news is shown at the first login (also in About This Computer).
- `lux configs`: merging new versions of configuration files.

### Changes
- lux is the only package manager: there is no `pacman` command in the system, the package engine is the `lux-engine` package (formerly `luxos-pacman`).
- Login screen: the wallpaper does not change when switching users, the profile slides smoothly.
- Store: "Update All" only when there are updates, a check error (network) is reported.
- Control Center: estimated remaining battery time; clicking the brightness icon opens Displays.
- Translucent notifications following light/dark mode.
- fastfetch: LuxOS Desktop and LuxOS Terminal instead of the Xfce names.
