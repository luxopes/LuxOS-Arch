## 0.9.9 "Polaris" – 2026-10-24 (beta)

### New
- **An encrypted disk never fails silently** (hook `luxos-boot` in `luxos-tweaks`): a wrong password shows "Wrong password, try again." on the splash screen and the console, with unlimited attempts (`systemd-cryptsetup@` restarts after 3 failures), and there is no timeout waiting for the device while you type the password. If the system disk does not appear within 90 s or boot ends in emergency mode, a boot log is saved to the EFI partition (`\EFI\LuxOS\boot-failure-*.log`, last 5) and an explanation with next steps is shown.
- `lux check` (available updates without installing), manual page `man lux`; lux deletes and re-downloads a corrupted downloaded package by itself (also in Lux Store).
- The installer adds other systems from a shared EFI partition (Debian, Ubuntu, Fedora, …) to the boot menu and puts LuxOS first in the UEFI boot order.
- Printers whose driver is only available from the vendor (AUR, e.g. Samsung Xpress M2026/SPL): instead of a broken printer, a notification with an "Install driver" button.
- Scanner: a camera is no longer offered as a scanner, and a scanner switched on later is found by itself (search every 6 s, "Search again" button). Fingerprint: a "Try again" button after a failed scan.

### Fixes
- **Installing next to another system into an existing LUKS + LVM** (Debian): disk unlocking at boot was missing (`rd.luks.name`, `sd-encrypt`) and the system ended in emergency mode; installing from a configuration file stopped at the check of the locked LVM group; the name of the new volume was not saved (always "root", clashing with Debian's volume).
- Installer: an eye icon on all password fields, a bigger window (encryption password fields visible without full screen).
- Ventoy in normal mode ("INIT NOT FOUND"): live ISO initramfs without the `kms` hook (229 → 66 MB), ISO 2.42 → 2.10 GB.
- Lux Store "Could not check for updates": on computers with a shared EFI, `lux_alpm` refused because of `HookDir` (only for transactions), signature verification as the user (copy of the keys), mismatched copy of the database and its signature (now downloaded afresh).
- Lux Guard does not run in the live system from USB (it warned about the installer itself).
- Launchpad and Search: no selection by hovering – no scrolling by itself, and Enter launches the first (best) match.
- "Internet is not available" after every login: the warning comes only after 20 s of continuous outage, not in the first minute.
- LuxAI 1.0.0-12: the agent does not announce an action without doing it (it nudges itself to act once), root commands without `pkexec` (administrator mode).
