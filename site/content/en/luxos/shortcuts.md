# Keyboard shortcuts

LuxOS uses the **Super** key (the Windows key) where macOS uses Cmd. All global shortcuts can be
shown and changed in the **Keyboard Shortcuts** app (`luxos-shortcuts`); keyboard layouts are set in
**Keyboard Layouts** (see [Keyboard layouts and shortcuts](keyboard.html)).

## Desktop

| Shortcut | Action |
|---|---|
| `Super+Space` | Search (also takes questions for LuxAI) |
| `Super+A` or `Super` alone | Launchpad |
| `Super+Q` | close the window |
| `Super+M` / `Super+H` | minimise |
| `Super+Tab` | switch windows |
| `Super+↑` / `Super+←` / `Super+→` | maximise / half screen |
| `Ctrl+Super+F` | full screen |
| `Super+Shift+3` / `4` / `5` | screenshot of the screen / of a selection / screenshot tool |
| `Super+L` or `Ctrl+Super+Q` | lock the screen |
| `Super+Alt+Esc` | task manager (force quit) |
| `Super+,` | Settings |
| `Super+P` | displays: extend, mirror, external only, built-in only |
| Calculator key | LuxOS Calculator |

## LuxAI

| Shortcut | Action |
|---|---|
| `Enter` | send (or `Ctrl+Enter`, see Settings) |
| `Esc` | stop the answer or a running command |
| `Ctrl+N` | new conversation |
| `Ctrl+F` | search conversations |
| `Ctrl+,` | settings |
| `Ctrl+V` | paste an image or files |
| `Ctrl+Q` | quit |

## Lux Code

| Shortcut | Action |
|---|---|
| `Enter` / `Alt+Enter` | send / new line |
| `Ctrl+C` or `Esc` | interrupt; `Ctrl+C` on an empty line quits |
| `Ctrl+V` | attach an image |
| `F2` / `F3` | changes and plan / tool details |
| `/` | command suggestions |

## Keyboard layouts

By default, press both Shift keys together to switch layouts. Other options (Alt+Shift, Ctrl+Shift,
Caps Lock, the Menu key, or only the flag in the top bar) are in Keyboard Layouts.
