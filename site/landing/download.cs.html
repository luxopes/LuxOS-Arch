Ověření staženého souboru

Ověřte, že je soubor celý a opravdu pochází od LuxOS. Dejte ISO, SHA256SUMS a soubor .sig do jedné složky a v terminálu spusťte:

$ sha256sum -c SHA256SUMS
$ gpg --import luxos.gpg
$ gpg --verify {{ISO_FILE}}.sig {{ISO_FILE}}
SHA-256:{{ISO_SHA256}}
Otisk klíče LuxOS:{{FINGERPRINT}}

sha256sum musí vypsat OK (v češtině V POŘÁDKU) a gpg Good signature (Dobrý podpis) klíčem s otiskem výše. Ve Windows porovnejte součet příkazem Get-FileHash .\{{ISO_FILE}} v PowerShellu, na Macu příkazem shasum -a 256 {{ISO_FILE}}. Podpis ve Windows ověříte programem Gpg4win.

Zápis ISO na USB disk

Všechno na USB disku se smaže. Vyberte jeden nástroj:

  • Ventoy (Windows, Linux): Ventoy na disk jednou nainstalujete a pak na něj ISO jen zkopírujete – na jednom disku můžete mít víc systémů. Se zapnutým Secure Boot při instalaci Ventoy na disk zapněte volbu Secure Boot Support.
  • balenaEtcher (Windows, macOS, Linux): Flash from file → vyberte ISO → vyberte USB disk → Flash.
  • Fedora Media Writer (Windows, macOS, Linux): zvolte vlastní soubor .iso (Select .iso file) → vyberte disk → zapište.
  • Rufus (Windows): vyberte ISO a až se Rufus zeptá, zvolte zápis v režimu DD.
  • dd (Linux): najděte USB disk příkazem lsblk (třeba /dev/sdb – zkontrolujte to dvakrát, špatné zařízení znamená ztracená data) a spusťte sudo dd if={{ISO_FILE}} of=/dev/sdX bs=4M status=progress oflag=sync.

Secure Boot nechte zapnutý

LuxOS startuje se zapnutým Secure Boot – ve firmwaru nemusíte nic měnit. Při úplně prvním startu z USB disku se počítač jednou zeptá, jestli má důvěřovat klíči LuxOS: stiskněte Enter, zvolte Enroll key from disk, vyberte klíč LuxOS a potvrďte. Trvá to méně než minutu a nic se nepíše. Návod krok za krokem se snímky.

Vyzkoušení a instalace

  1. Zasuňte USB disk, zapněte počítač a otevřete nabídku spouštění – obvykle F12, F11, F8 nebo Esc.
  2. LuxOS se spustí z USB disku. Vyzkoušejte Wi-Fi, zvuk a grafiku.
  3. Spusťte Nainstalovat LuxOS. Vyberte celý disk, volné místo vedle Windows (dual boot) nebo existující oddíl, volitelně se šifrováním.
  4. Po instalaci se LuxOS aktualizuje sám na pozadí; každou aktualizaci jde vrátit.

Časté otázky

Je LuxOS zdarma?

Ano. ISO stáhnete i používáte zdarma, bez registrace a bez placené edice. Většina LuxOS je otevřený software pod licencí GPL-3.0-or-later.

Musím vypnout Secure Boot?

Ne. LuxOS startuje se zapnutým Secure Boot. Při prvním startu z USB disku se počítač jednou zeptá, jestli má důvěřovat klíči LuxOS, což trvá méně než minutu.

Můžu LuxOS vyzkoušet bez instalace?

Ano. LuxOS běží přímo z USB disku. Na vašem disku se nic nezmění, dokud nespustíte instalátor a nevyberete, kam instalovat.

Který soubor potřebuju?

Jen soubor ISO. SHA256SUMS, podpis .sig a klíč LuxOS slouží k ověření, že je stažený soubor celý a pravý.
