Linux for old computers

An older PC or laptop is often too slow for today's Windows, or not allowed to run Windows 11 at all – but still good for the web, documents, photos and video calls. LuxOS is a free, lightweight Linux that gives such computers a second life, with a modern desktop.

Right after login LuxOS uses roughly 1 to 1.4 GB of RAM, depending on the hardware – in our 4 GB test machine it was under 1 GB, leaving the rest to your apps. The ISO you download is {{ISO_SIZE}}.

Why it stays fast on older hardware

  • Lightweight desktop: built from Xfce components, which need far less memory and graphics power than heavier desktops, yet looks modern.
  • Compressed memory (zram): when RAM gets full, LuxOS compresses memory instead of swapping to a slow disk.
  • No freezing when memory runs out: if one program eats all memory, LuxOS stops just that program and tells you, instead of the whole computer locking up.
  • Compressed file system (Btrfs with zstd) saves space on small disks.
  • Ad blocker in Firefox out of the box: fewer scripts and ads mean lighter web pages.
  • Battery Saver and Data Saver in Control Center for older laptops and mobile hotspots.
  • Own native apps such as Terminal and Text Editor, written in C or LSL rather than heavy frameworks.

Older hardware and drivers

LuxOS detects the hardware during installation and after every start: Intel and AMD graphics work out of the box, NVIDIA cards get the right driver for their generation (newer ones the open NVIDIA driver, Maxwell to Volta the 580xx driver, older cards the open-source nouveau), Broadcom Wi-Fi chips get their driver, and printers usually work without installing anything. Details are in hardware support.

Tips that help most

  1. Replace a spinning hard disk with an SSD. It is the biggest speed-up for an old computer and costs little.
  2. Add RAM if you can: going from 4 to 8 GB makes many browser tabs comfortable.
  3. Try it from USB first: LuxOS runs from the stick without installing, so you see whether Wi-Fi, sound and graphics work before you change anything.

Honest limits

  • 32-bit processors and Apple Silicon Macs are not supported.
  • On 4 GB of RAM, heavy web apps and dozens of tabs will still be slow – that is the browser, not the system.
  • Installation downloads current packages, so it needs an internet connection.
  • LuxOS is young. For a very old machine that must just work, lighter established systems such as Linux Mint Xfce or Zorin OS Lite are worth a look too.

Common questions

How much RAM does LuxOS need?

4 GB is the minimum we test installation on; after login LuxOS itself uses roughly 1 to 1.4 GB. 8 GB is recommended if you keep many browser tabs open.

Does LuxOS work on a computer without UEFI?

Yes. LuxOS installs on computers with UEFI and on older ones with legacy BIOS. A TPM chip is not needed.

Can I install LuxOS on a computer that cannot run Windows 11?

Yes, as long as it has a 64-bit processor, at least 4 GB of RAM and a 20 GB disk. LuxOS has none of the TPM or processor-generation requirements of Windows 11.
