# Překlady

LuxOS má sdílené tabulky překladů: `/usr/share/luxos/i18n/<jazyk>.tsv` (balíček `luxos-i18n`).
Každý řádek obsahuje `anglický text<TAB>překlad`. Řádky s `#` jsou komentáře a prázdný překlad
znamená anglický text. Jazyk se bere z `LC_ALL`, `LC_MESSAGES` nebo `LANG`. Podporované jazyky:
cs, de, es, fr, hu, it, nl, pl, pt, sk, sv, uk.

Tabulky jsou pro programy LuxOS. Vlastní aplikace si nese vlastní překlady (gettext, Qt `.qm`, i18next…).
Pomocníci níže se ale hodí pro rychlé skripty a nástroje a zaručí stejné výrazy jako v systému
(„Otevřít“, „Smazat“, „Nastavení…“).

## Python

```python
import sys
sys.path.insert(0, "/usr/lib/luxos/python")
from luxos_i18n import _

print(_("Open"))          # "Otevřít" v češtině
```

## Bash

```bash
. /usr/lib/luxos/i18n.sh
T "Open"; echo
T "New messages: %d" 3; echo   # printf formát: %s, %d
```

## LSL (programy v repozitáři LuxOS)

```
load luxos_i18n as i18n
print i18n.T("Open")
print i18n.TF("New messages: %d", [3])
```

## Přidání textu do systému

1. Přidejte řádek do každého `packages/luxos-i18n/files/<jazyk>.tsv`. Zástupné znaky `%s`/`%d`
   musí v překladu zůstat.
2. `LUXOS_I18N_DIR=packages/luxos-i18n/files` přesměruje překlady pro testy bez instalace balíčku.
