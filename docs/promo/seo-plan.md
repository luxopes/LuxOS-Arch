# SEO plan for luxos.lux-ai.cz (phase 2)

Audit of the site as built by `scripts/build-site.py` at commit 7b7e194 (after the light-background /
logo / screenshot work), and the changes for phase 2. Status of each item is marked:
**[done]** = implemented in the phase 2 commit, **[owner]** = needs the site owner (accounts, DNS).

## 1. What is already good (keep)

- Unique `<title>` and meta description on every page (checked by `check-site.py`), canonical URLs,
  `hreflang` en/cs + `x-default`, one `<h1>`, `alt` on images.
- OpenGraph + Twitter `summary_large_image` on every page with a 1200×630 JPEG (`/assets/og-image.jpg`).
- `sitemap.xml` with `xhtml:link` alternates, `robots.txt` with the Sitemap line; `/download/` is
  disallowed (redirect page + ISO files – correct, no need to index binaries).
- JSON-LD: WebSite + SoftwareApplication on the home pages, TechArticle + BreadcrumbList on docs,
  FAQPage on the FAQ, BreadcrumbList on changes/usage/legal pages.

## 4. FAQ content (implemented in `site/content/{en,cs}/luxos/faq.md`)

Questions, in this order: What is LuxOS? · Is LuxOS free? What licence? · Who makes LuxOS? · Is LuxOS
safe to use? Is it finished? (beta) · How is LuxOS different from Ubuntu, Linux Mint or Zorin OS? ·
… from elementary OS? · … from Arch Linux, Manjaro or EndeavourOS? · Does LuxOS run Windows apps? ·
Can I play games / use Steam? · What hardware does LuxOS need? · How do I install? · Dual boot? ·
How do I update? · Can I undo an update? · Where is pacman? · What is LuxAI / do I need it? ·
Account? · What is Lux Code? · What is LSL? · Malware protection? · Verify ISO? · NVIDIA? ·
LuxDrop? · Languages? · What if something breaks? · Where do I report bugs?

Rules used: every answer verifiable in the repo docs; no RAM minimum is stated because none is
documented (the answer says so and gives the tested VM size only as an indication); Windows apps:
Wine/Bottles are available from the repositories/Flathub, no promise of compatibility; Steam: the
"Gaming" app set in the installer and `multilib`, Performance mode on hybrid GPUs.

## 5. Comparison page (implemented in `site/content/{en,cs}/luxos/compare.md`)

A table + short sections: base, desktop, package management, updates/rollback, kernel, drivers,
security defaults, AI, maturity/support, who should pick which. Facts about other distros are kept
general and stable (e.g. Ubuntu = Debian base, GNOME, apt + Snap; Mint = Ubuntu base, Cinnamon;
Zorin = Ubuntu base, layouts that mimic Windows/macOS; elementary = Ubuntu base, Pantheon, AppCenter
with Flatpak; Arch = DIY; Manjaro = delayed Arch packages, own repos; EndeavourOS = near-vanilla Arch
with an installer). Explicitly says where the others are better (maturity, community, support,
LTS releases).

## 6. llms.txt

`/llms.txt` follows <https://llmstxt.org>: `# LuxOS`, a `>` summary, a short "facts" list (base,
version, status, licence, kernel, package manager, author, contact – all from the build data), then
sections `## Docs`, `## Download`, `## Project`, `## Optional` with Markdown links to the HTML pages
and one-line descriptions taken from the docs index. `/llms-full.txt` concatenates the English FAQ,
comparison, overview, hardware, installer, package management, LuxOS Care, Lux Guard and LuxAI docs as Markdown (~100 KB). Both are regenerated on every build so
the version can't go stale.

## 7. Search engine setup – steps for the owner **[owner]**

### Google Search Console
1. <https://search.google.com/search-console> → Add property → **Domain** `lux-ai.cz` (covers all
   subdomains) → add the TXT record at the DNS provider → Verify. (A URL-prefix property for
   `https://luxos.lux-ai.cz/` works too and can be verified with an HTML file or meta tag; the domain
   is already verified for the OAuth app, so check whether the property already exists.)
2. Sitemaps → submit `https://luxos.lux-ai.cz/sitemap.xml`.
3. URL Inspection → `https://luxos.lux-ai.cz/` and `/cs/` → Request indexing (once, after publishing).
4. After a week: Pages report (not indexed reasons), Enhancements (breadcrumbs), International
   targeting is automatic from hreflang.
5. Rich results test (<https://search.google.com/test/rich-results>) for `/` and
   `/docs/luxos/faq.html`. Note: Google shows FAQ rich results only for authoritative gov/health sites
   since 2023, and SoftwareApplication rich results need ratings – the markup is still useful for
   understanding, just don't expect stars.

### Bing Webmaster Tools
1. <https://www.bing.com/webmasters> → sign in → **Import from Google Search Console** (fastest) or
   add the site and verify (XML file / meta tag / DNS CNAME).
2. Submit the sitemap. Bing also feeds DuckDuckGo, Ecosia and many AI assistants' web search.

### IndexNow (Bing, Yandex, Seznam.cz, Naver – Google does not use it)
- The build publishes the key file `https://luxos.lux-ai.cz/<key>.txt` (key in `site/indexnow-key.txt`).
  The key is public by design; it only proves you control the host.
- After each `scripts/publish-site.sh`, run `scripts/indexnow-submit.sh` (submits every sitemap URL in
  one POST to `https://api.indexnow.org/indexnow`; prints the HTTP status; 200/202 = accepted). Run it
  only after the files are live, otherwise the key check fails.
- **Seznam.cz** supports IndexNow, which matters for Czech searches; also register at
  <https://search.seznam.cz/> "Seznam Webmaster" and submit the sitemap.

## 8. Off-site signals (link building without spam)
- GitHub repo: website field, topics, social preview (see github.md).
- DistroWatch entry (see distrowatch-submission.md), AlternativeTo listing, Wikidata item (later).
- Link from lux-ai.cz and lsl.lux-ai.cz to luxos.lux-ai.cz (same owner – fine, helps discovery).
- Each independent article = a real backlink; never buy links or use link farms.
