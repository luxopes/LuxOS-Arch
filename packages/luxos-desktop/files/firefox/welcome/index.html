Firefox is ready. A few tips to make yourself at home.

Bring your bookmarks and passwords

Firefox can import bookmarks, passwords and history from Chrome, Edge or Chromium on this computer, or from files exported on Windows (bookmarks as HTML, passwords as CSV).

Import from another browser

Later: menu ☰ → Settings → General → Import browser data.

Privacy set up by LuxOS

  • No telemetry or technical data is sent to Mozilla
  • No studies or experiments
  • No sponsored shortcuts or stories on the new tab page

You can change this in Settings → Privacy & Security.
